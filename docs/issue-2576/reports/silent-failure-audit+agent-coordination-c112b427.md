## Why

Root cause, one sentence: composed multi-skill branch/lease identities join skill names with `+` (this session's own is `silent-failure-audit+agent-coordination-c112b427`), and almost every branch-derived identity site in `on-the-record/hooks/` used `[\w-]+` or `[A-Za-z0-9_-]+` — neither includes `+` — so the *whole* branch-regex silently fails to match on any composed-skill session, and every check gated on that match (an approval requirement, a merge-trailer requirement, a sibling-mention check, a deviation-log scope, a PR-base fail-closed gate, a product-capture write) goes dark with no error, no log, no denial. This is exactly Kind 3 from the issue: a hook branching on a role-shaped value that a slug simply fails to match.
canonical: `git diff on-the-record/hooks/approval-gate.sh on-the-record/hooks/contract-guard.sh on-the-record/hooks/pr-preflight.sh on-the-record/hooks/post-landing-obligation-gate.sh` (this commit) — every widened-regex hunk in that diff replaces `[\w-]+`/`[A-Za-z0-9_-]+` with `[^/]+`.
