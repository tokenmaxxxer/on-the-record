# Deviation: switched A/B comparison method mid-session

Used `git checkout origin/main -- .` then `git checkout pr-2855-review -- .` (partial-path
checkouts, no full branch switch) to compare before/after failing-test sets. This left a corrupted
mixed working tree/index (partial checkouts don't remove files present in the prior ref's tree but
absent from the target ref), producing a bogus before/after diff (spurious `test/test_self_update_*`
failures that were not part of either real ref).

Detected via `git status --short` showing an unexpected mix of staged additions/modifications instead
of a clean two-state comparison. Recovered with `git reset --hard HEAD` and switched the entire rest
of the session's A/B testing (failing-test-set comparison, overhead re-measurement, monitor/watch
invariant checks) to `git worktree add /tmp/wt-main origin/main` / `git worktree add /tmp/wt-pr
pr-2855-review`, which isolates each ref's full working tree and avoids the mixed-state failure mode.
Both worktrees were removed (`git worktree remove --force`) once the comparisons were captured.
