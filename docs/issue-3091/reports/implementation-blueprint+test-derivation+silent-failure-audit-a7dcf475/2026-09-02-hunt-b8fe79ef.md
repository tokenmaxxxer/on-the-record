canonical: b8fe79ef:gates/probe_full_suite_is_one_command.py:104-106 — source read this turn:
```python
def _is_shell_test_candidate(relpath: str) -> bool:
    p = Path(relpath)
    return p.parent == Path("tests") and p.name.endswith(".sh")
```
`p.parent == Path("tests")` is true only for files exactly one level under `tests/`; a file nested one level deeper (as reproduced above at `tests/subdir/evil.test.sh`, untracked, and generalizing to any sibling directory like `test/`, which the pre-b8fe79ef blanket repo-wide check would have caught per the file's own docstring at lines 4-8) never enters `shell_candidates` (line 151-152 of the same file), so it is checked against neither `KNOWN_SHELL_TEST_COMMANDS` nor pytest's collected-files set, matching the reproduce transcript above showing exit 0 / "ok" despite the file's presence.
