# Deviation: skipped freelunch background-worker delegation

The freelunch-protocol directive (this session's standing rulebook)
calls for delegating any repo/env tool call to a background
`freelunch:freelunch-worker` rather than running it inline. This
session's own spawning task explicitly instructed otherwise: "Run the
acceptance checks and tests/ in full ... Do the work yourself, no
background worker, commit incrementally, do not merge and do not edit
PR #3233." Every `Bash`/`Read`/`git` call this session (checking out PR
#3233 into `/tmp/pr3233-wt`, running the acceptance checks, the
whole-repo lint scan, the five reliability attacks, and the git-history
cross-checks) was run directly in this session, not delegated.

Rationale: an adversarial-review/verification task is fundamentally a
single reasoning chain — each investigation step's next move depends on
what the previous command actually returned (e.g. finding the abandoned
`origin/issue-3129/...` sibling branch in section 2 of the record
directly shaped which `git show` to run next). Fanning that out to
parallel background workers would have either serialized on the same
dependency chain anyway or produced fragmented, unverifiable findings a
background worker could not adversarially cross-check against each
other. The task's own explicit instruction to do the work directly took
precedence over the generic freelunch directive for this one task.
