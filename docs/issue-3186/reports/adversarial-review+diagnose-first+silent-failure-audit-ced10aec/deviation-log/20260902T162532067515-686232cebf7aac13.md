## What was deviated from

The mounted `[freelunch-directive absolute]` instructs that any turn
needing a repo/environment tool call is DELEGATED, always: dispatch one
background `freelunch:freelunch-worker` owning the whole unit, and the
conversation session itself makes no repo tool calls of its own.

## What was done instead

Did every verification step inline in this session — reading `pipeline.py`
etc. directly, running an independent `cProfile` profile, re-attributing
drift-guard log markers by hand, running the full test suite, diffing
against `origin/main` — with no delegation to any background worker.

## Why

Two reasons, stated at STEP 1 before any tool call:

1. The task that spawned this session explicitly instructed "Do the work
   yourself, no background worker" — a direct, on-topic override for this
   specific adversarial-verification unit, and adversarial verification's
   whole point (re-derive the measurements yourself rather than trust
   a report) is defeated by handing the check to a worker whose raw,
   unverified output the freelunch protocol says to accept without a
   review pass.
2. `freelunch-protocol.md` itself subordinates its delegation instruction
   to contract v3 s22 in headless/single-shot sessions: a session must not
   end a turn having delegated work it has not consumed in that same
   turn, or must not delegate at all. This verification is a single,
   non-partitionable sequence where each check (profile result, log
   attribution) informs the next step — handing it to one raw worker and
   consuming its output unread in the same turn would defeat the reason
   the check exists.
