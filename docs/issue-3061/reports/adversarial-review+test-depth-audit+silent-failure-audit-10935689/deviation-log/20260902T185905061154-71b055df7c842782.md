# Deviation: record-claim-guard rejected the first two full-record Write attempts

Expected the first full draft of
`docs/issue-3061/reports/adversarial-review+test-depth-audit+silent-failure-audit-10935689.md`
to pass `record-claim-guard.sh` on the first `Write`, since all
substantive numbers/claims already had `derived:`/`canonical:` evidence
gathered before drafting (per `record-order.md`'s guidance to assemble
once from executed results). That did not hold in practice.

derived: this session's own tool-call transcript — the first `Write`
was rejected for (a) a bare "6/7" token inside prose being parsed as an
uncited count claim, (b) two status/defect claims in the "Why" section
lacking a `canonical:`/`derived:` tag in the same section, and (c) two
references to `test/test_delegation_state.py` (a path real only on PR
#3087's branch, untracked on this record's own branch) read as a
broken-reach reference. The second `Write`, after fixing (a)-(c) and
adding the untracked-path caveat, was rejected once more for a third
status/defect claim in a `skill-verdict` paragraph lacking its own
`canonical:`/`derived:` tag in the same block. The third attempt, with
the tag moved immediately adjacent to the claim, passed.

Correction: no content was removed or weakened — every rejection was
resolved by adding the missing citation tag or path-reach caveat next
to the existing claim, never by deleting the claim itself. The
substance of the verification (five items graded, one Incorrect finding
on `tuple`) was unchanged across all three attempts; only the record's
own citation shape needed three passes to satisfy the gate.

Why this happened despite following record-order.md: that guidance
governs *when* to assemble the record (once, after checks run), not
*how densely* every individual status claim needs an adjacent tag
within its own section — a multi-item verification record with several
"Why"-style summary sentences turned out to need more inline
`canonical:`/`derived:` repetition per section than a single-finding
record would, which was not obvious until the gate flagged it.
