bypass must be DENIED in every form the three prior rejections

unchanged, (b) added a documentation-only comment naming the open
bypass and why no fix was attempted, and (c) added three
`@unittest.expectedFailure` regression tests so the gap is visible in
`pytest` output and in the code, rather than silently unaddressed.
canonical: the same record's "Open findings" §1 — the consult the task
itself cites already concluded no path-shaped formulation here can be
