# Scout brief: pr-communications operational playbook (issue #1174)

Mode: parallel WebSearch fan-out, 1 sweep stage, 4 angles in one batch
(practitioner planning framework, crisis/Q&A prep, evaluation
standards, academic persuasion theory) — no fallback to
batched-sequential needed.

## Angle 1 — practitioner planning framework (RACE, message house)
- RACE = Research/Action/Communication/Evaluation (Cutlip & Center's
  four-step model, popularized by Marston 1963).
- Three-tier message house: core message (exactly one) + supporting
  messages + proof points per message.
Sources:
- https://2012books.lardbucket.org/books/public-relations/s10-the-public-relations-process-r.html
- https://pracademy.co.uk/insights/pr-planning-toolkit/

## Angle 2 — crisis communication / Q&A prep / sign-off
- Pre-approved holding statements and message maps drafted before a
  crisis, not during one.
- Explicit approval workflow (PR/comms -> legal if factual/liability
  claim -> executive), turnaround times documented.
- One shared statement across all spokespeople on the same question.
Sources:
- https://jobs.prsa.org/career-resources/finding-talent-10/crisis-communications-checklist-24-hour-response-protocol-405
- https://jobs.prsa.org/career-resources/finding-talent-10/crisis-communication-plan-a-checklist-381
- https://jobs.prsa.org/career-resources/finding-talent-10/executive-communications-during-crisis-spokesperson-preparation-guide-409

## Angle 3 — evaluation standards
- Barcelona Principles 4.0 (AMEC, June 2025): measure outputs,
  outtakes, outcomes, and impact as a chain — outcome must trace to a
  measured outtake, not be asserted directly on top of outputs.
Sources:
- https://amecorg.com/resources/barcelona-principles-4-0/

## Angle 4 — academic theory (persuasion, comprehension)
- Aristotle's ethos/pathos/logos: match the appeal to the audience's
  actual objection (factual vs. credibility vs. emotional).
- Kahneman & Tversky prospect theory / framing effects: an implicit
  loss reads worse once discovered than an explicit one.
Sources:
- https://www.davidpublisher.com/Public/uploads/Contribute/5cc1077dd950d.pdf
- https://virtualspeech.com/blog/ethos-pathos-logos-public-speaking-persuasion
- https://www.ebsco.com/research-starters/social-sciences-and-humanities/theories-persuasion

## Judgment point (single round, saturation reached)
Overlap across angles converged on the same shape the role's own spec
already implies (objective -> channel -> output/outtake/outcome): a
one-core/N-supporting message hierarchy with sourced proof points,
pre-cleared Q&A, and a Barcelona-shaped evaluation chain. One round was
sufficient — a second round was judged unlikely to change which axes
to build rules for, so deepening stopped here (budget: 1 stage used of
5, well under the 3-min wall-clock cap).

objective-channel-fit, message-hierarchy, approval-sequencing,

## Gap line
The role's spec already structures the objective/channel/output/
outtake/outcome fields; what it leaves open is HOW to choose between
channels, HOW to build the message hierarchy, WHEN Q&A needs sign-off,
and WHAT the evaluation chain requires before a claim is treated as
verified — the 13 rules in the landed playbook target exactly those
gaps. Out of scope for this scout round, left as an open finding:
channel-specific release-timing/embargo mechanics (the four fetched
sources above cover planning/message/evaluation, not release-timing).
