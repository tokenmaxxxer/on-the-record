## Priority: bounded-fix-round philosophy for gate-registration-guard.sh's cwd model (issue #2705)

Stated in this session's own spawning task (restating a bound the
operator set in an earlier round on this same issue, also captured
separately in PR #2774's own record): a shape-by-shape adversarial-review
loop on `gate-registration-guard.sh`'s cwd parser should not run
indefinitely. If a review round finds a *fresh* cwd-tracking bypass
beyond the ones the previous round was explicitly asked to fix, that is
a signal to reconsider the parsing approach itself (a different seam, or
an explicit statement of what the parser does not cover), not license
for a fourth/fifth/Nth single-shape patch cycle.

This session's own verification of PR #2774 (see
`docs/issue-2705/reports/adversarial-review-b6638c90.md`) found exactly
that: a second consecutive round turning up a fresh gap in the same
`pushd`/`popd` family the immediately preceding round claimed to have
closed (bare `pushd`, `pushd +N`/`-N` rotation — see that record's Open
findings). Whoever next picks up issue #2705 should weigh this priority
before authoring a fifth single-shape patch: the bound as stated treats
two consecutive fresh-gap rounds in the same family as meaningfully
different from two fresh gaps found across independent families.
