The operator stated a standing verification-severity principle, specific to reviewing changes to observation/monitoring machinery itself: **a PR that changes the thing that watches everything else must be reviewed as the highest-severity case available, because a regression there is invisible by construction — a quieter watchdog looks exactly like a calm system.**

Concretely, in the order the operator gave it:

1. Attack the root-cause claim first, from source and by running the mechanism to a real exit — not by trusting the subject record's own assertion — and always check the converse of a durability claim (here: does the fix's own new queue survive a crash between recording and draining, or has the blind spot just moved rather than closed).
2. Reconstruct every state the mechanism claims to distinguish live, using the exact failure case that originally fooled the operator (file-diff cannot tell "investigating" from "stalled" when the touched files were already dirty) — an assertion that a mechanism distinguishes N states is not verified until all N have actually been produced and compared.
3. Measure cost at the scale that matters (an idle tick, one session, and a small fleet), not just a single before/after test count — a mechanism that runs every tick has a cost profile, not a binary correctness verdict.
4. Verify a design rationale (here: absolute vs. relative timestamp, specifically chosen to survive delta-suppression) by actually exercising the suppression logic across consecutive ticks, not by reading the stated rationale and accepting it.
5. Standing invariants (no retired-axis return, no new test failures as sets of names, no overhead increase, and — specific to this kind of change — "not quieter": enumerate every signal that existed before and show each still fires) should each be checked with its own command and its own output, not a single aggregate claim.

This generalizes beyond issue #2904: any future review of code that changes logging, monitoring, heartbeat, or watchdog machinery should apply this same severity — adversarial, live, and structured around "what does a regression here look like, and would it be silent."
