- 2026-08-30: discovered while independently verifying PR #2816 (issue
  #2811): `$CLAUDE_PLUGIN_ROOT_CORE` points to a subdirectory (`core/`)
  of the larger `tokenmaxxxer-core` git repo, not that repo's toplevel —
  the repo also contains sibling top-level dirs (`scripts/`, `warrant/`,
  `test/`, `tests/`) that are separate plugins/areas. Running `git
  ls-files` from the repo's `git rev-parse --show-toplevel` instead of
  from `$CLAUDE_PLUGIN_ROOT_CORE` itself silently pulls those sibling
  areas into a "core plugin" population count (5 files vs. the correct
  3). Confirmed by reproducing both and diffing. Future sessions
  computing a population/sweep scoped to "the core plugin" in
  tokenmaxxxer-core should `cd`/`git -C` into `$CLAUDE_PLUGIN_ROOT_CORE`
  itself (not its outer repo toplevel) before running `git ls-files`,
  or they will silently over-count. Source: this session's own
  re-derivation, docs/issue-2811/reports/independent-verification-1.md.
