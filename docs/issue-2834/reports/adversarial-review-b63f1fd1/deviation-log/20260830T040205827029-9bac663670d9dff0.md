# Deviation: inline execution instead of freelunch background delegation

This session's UserPromptSubmit carried a `freelunch-directive` requiring
every repo/environment tool call to be delegated to a background
`freelunch:freelunch-worker` subagent, never run inline. I did not do
this — every `Bash`/`Read`/`Write`/`git worktree` call in this session ran
inline, in my own turn.

**Why**: the same directive is explicitly subordinate, in headless/
single-shot sessions, to contract v3 s22: "a role session running
headless... must not end a turn having delegated work whose result it has
not consumed within that same turn... wait for the delegated result and
act on it before the turn ends, **or do not delegate that unit at all**."
This session's own completion-and-landing directive states background
work dies when the parent turn ends in this environment. The adversarial-
review task itself (sweep two repos, build and iterate on a live repro
fixture, run before/after benchmarks, synthesize a record) is also
sequential and judgment-heavy end to end — width 1, not a fan-out
candidate even ignoring the headless risk. I stated this reasoning as the
mandated STEP 1 tally at the start of the turn and used the directive's
own sanctioned fallback ("or do not delegate that unit at all") rather
than risk losing verification work to a background task that could not
outlive the turn.

**What did not work initially, fixed inline**: my first independent repro
fixture (`/tmp/adv2834_bench.py`, mode `repro`) wrote a synthetic
session-start event to the wrong path/shape (`.on-the-record/events/
session-start.json` with a top-level `pid` field), so `session_end_verdict()`
returned `"normal"` instead of `"crashed"` and short-circuited
`diagnose_health()` to "completion" regardless of the branch-derivation
bug — masking the very misdiagnosis I was trying to reproduce.

canonical: `board.py:1175-1177` (`session_end_verdict()`) —
```python
    events_path = _sp._events_path(work)
    if not events_path.exists():
        return "normal"
```
— confirms the function needs the exact path `_sp._events_path(work)`
returns, not an arbitrary events directory. Fixed by writing to
`spawn._events_path(str(work))` (a `<work>.events.jsonl` sibling file)
with a `{"type": "session-start", "detail": {"pid": ...}}` shape,
matching the shape `board.py:1195-1197` reads (`detail.get("pid")`).

derived: `python3 /tmp/adv2834_bench.py repro /tmp/otr-main-bench` (after
the fix) — result: `diagnose_health() -> {'state': 'DEAD-ERRORED', ...
session_verdict='crashed'}` — confirms the fixture now exercises the
`crashed` path instead of short-circuiting to `normal`, matching the
full repro sequence documented in the main record.
